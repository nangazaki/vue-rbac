# create-vue-rbac
 
Official CLI for [vue-rbac](https://vue-rbac.nangazaki.io) — installs and configures RBAC in your Vue 3 project in seconds.
 
## Usage
 
Without installing anything:
 
```bash
npx create-vue-rbac
# or
npx create-vue-rbac init
```
 
With alternative package managers:
 
```bash
pnpm dlx create-vue-rbac
bunx create-vue-rbac
yarn dlx create-vue-rbac
```
